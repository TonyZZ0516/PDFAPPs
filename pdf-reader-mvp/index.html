End-to-End App Flow

EntryFast launch, local files first, no forced paywall.
E1 Launch

Show Home immediately with recent files, quick tools, and search ready.

E2 File Permission

Ask only when scanning or importing files, then explain what is accessed.

E3 Home State

If files exist, show recents; if not, offer Import PDF and Image to PDF.

E4 Return Path

After every task, return with the new file visible and open/share actions.

Read + EditReading is the default job; edits save as copies.
R1 Open PDF

Open recent/imported PDF to the last page with page count and file actions.

R2 Read

Support zoom, jump page, continuous scroll, search, bookmark, and night mode.

R3 Act on Page

Launch sign, highlight, pen, text note, or toolbox from the reader bottom bar.

R4 Save Copy

Never overwrite the source file; confirm the saved copy and keep undo-safe exits.

Tool TasksFocused utilities with preview before export.
T1 Select Tool

Choose Image to PDF, Sign, Compress, Merge, Split, or PDF to Image.

T2 Import Input

Use gallery, camera, recent PDFs, or current reader file as the input source.

T3 Prepare

Reorder, crop, select pages, adjust quality, place signature, or preview output.

T4 Export

Create the result, show progress, then offer Open, Share, Rename, and Find in Home.

Limits + RecoveryUpgrade prompts never block basic file access.
L1 Limit Check

Trigger Pro only on daily export limits, HD output, batch jobs, or saved libraries.

L2 Pro Sheet

Explain the benefit in context and keep Continue free available on the sheet.

L3 Error State

For failed loads or exports, show Retry, Open with, Save draft, and Contact support.

L4 Task Resume

Preserve selected files and edits when users return from Pro, permissions, or errors.
