# SwiftPDF Android PDF Reader + Converter MVP 产品需求文档

## 1. 产品定位

**产品名称：** SwiftPDF

**目标用户：** 学生、办公人群、自由职业者，以及需要在 Android 手机上快速打开、签名、转换和管理 PDF 的用户。

**产品策略：** 以“快速 PDF 阅读器”作为入口，通过 Image to PDF、签名、压缩、合并/拆分、PDF 转图片等高频工具承接用户任务，并在用户触发高级需求时引导 Pro 订阅。

**差异化方向：**
- 不在首次启动时强制弹订阅。
- 优先保证打开 PDF 快、路径短、广告克制。
- 工具功能聚焦，不做过重的全能 PDF Office。

## 2. 核心目标

- 用户打开 App 后，可以在 2 步内进入 PDF 阅读。
- 用户可以在 5 步内完成图片转 PDF。
- 用户可以在阅读器内完成签名并保存副本。
- 免费功能可完成基础任务，Pro 只在触发限制或高级功能时出现。
- 第一版范围适合 1-2 人小团队实现。

## 3. MVP 功能

### 3.1 首页与快速阅读

**需求描述：** 首页展示最近 PDF 文件和高频工具入口，让用户快速继续未完成任务。

**功能要求：**
- 自动展示最近打开的 PDF。
- 支持搜索、排序、重命名、分享、删除。
- 无文件时展示空状态，引导用户导入 PDF 或使用 Image to PDF。
- 阅读器支持缩放、跳页、连续滚动、夜间模式、书签。
- 首次打开不弹强制订阅页。

### 3.2 Image to PDF

**需求描述：** 支持把相册图片、截图、拍照内容转换成 PDF。

**功能要求：**
- 支持相册多选。
- 支持相机导入。
- 支持图片排序、裁剪、删除、预览。
- 支持导出 PDF，并提供打开/分享操作。
- 免费用户每日 3 次导出，Pro 用户不限次数。

### 3.3 签名与基础批注

**需求描述：** 用户可以在 PDF 内快速完成签名、批注，并保存为新副本。

**功能要求：**
- 支持手写创建签名。
- 支持从图片中提取签名。
- 支持在 PDF 页面上拖动、缩放、放置签名。
- 支持高亮、画笔、文本批注。
- 默认保存为副本，避免覆盖原文件。

### 3.4 PDF 工具箱

**需求描述：** 提供最常用的 PDF 工具，避免用户安装多个单点工具 App。

**功能要求：**
- 支持压缩、合并、拆分、PDF 转图片、Image to PDF、签名。
- 单文件基础处理免费。
- 批量处理、高质量压缩、高清导出属于 Pro 功能。
- Pro 提示只在用户触发限制时出现。

### 3.5 PDF 转图片

**需求描述：** 用户可以将 PDF 指定页面导出为 JPG 或 PNG，方便分享。

**功能要求：**
- 支持选择页码范围。
- 支持 JPG / PNG 格式。
- 普通清晰度免费。
- 高清导出为 Pro 功能。

## 4. 页面逻辑

| 页面 | 默认状态 | 主要操作 | 异常 / Pro 状态 |
|---|---|---|---|
| 首页 | 展示最近 PDF；未授权文件权限时展示权限说明 | 打开文件、搜索、排序、重命名、分享、删除、进入工具 | 无文件时展示空状态，不弹订阅 |
| 阅读器 | 打开上次阅读位置，展示顶部文件栏和底部工具栏 | 搜索、书签、签名、批注、工具箱、跳页、夜间模式 | 文件打开失败时提供重试和“用其他应用打开” |
| Image to PDF | 从相册/相机导入图片 | 排序、裁剪、删除、预览、导出、分享 | 免费 3 次用完后展示 Pro 弹层，可继续返回 |
| 签名 | 绘制签名或从图片导入 | 放置、缩放、移动、确认、保存副本 | 签名库和无限保存签名属于 Pro |
| 工具箱 | 展示六个高频工具 | 压缩、合并、拆分、PDF 转图片、图片转 PDF、签名 | 批量、高质量、高清能力触发 Pro |

## 5. 商业化规则

**免费版：**
- PDF 阅读和文件管理。
- 每日 3 次 Image to PDF。
- 基础签名。
- 普通 PDF 转图片。
- 基础压缩、合并、拆分。

**Pro：**
- 去广告。
- 不限转换次数。
- 批量处理。
- 高清导出。
- 高质量压缩。
- 无限签名和签名库。

**Paywall 原则：**
- 不在首次启动弹出。
- 不阻塞基础阅读。
- 只在用户触发限制或高级功能时出现。
- 必须提供关闭或继续免费使用入口。

## 6. V1 不做

- 不做 PDF to Word。
- 不做 OCR。
- 不做 AI 摘要、翻译、朗读。
- 不做云同步。
- 不做协同编辑。
- 不做 iOS。
